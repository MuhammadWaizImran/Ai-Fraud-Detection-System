SYSTEM ARCHITECTURE

Medallion Delta Lakehouse Architecture

Designed on Azure Databricks, Apache Spark Structured Streaming, and Delta Lake ACID transaction tables.

1. Ingestion & Lakehouse Storage

High-throughput market order events are streamed into Azure Event Hubs. Databricks Spark Structured Streaming ingests raw payloads into Bronze Delta, deduplicates and validates schema into Silver Delta, and computes rolling window microstructural features into Gold Delta (150,000+ Vectors).

2. AI Scoring & Real-Time Delivery

Transactions are normalized via StandardScaler and evaluated in parallel across XGBoost, Isolation Forest, and PyTorch Autoencoders. High-risk transactions (Score ≥ 0.85) trigger Azure Logic Apps webhooks and pulse the 3D Three.js Web Command Center.
